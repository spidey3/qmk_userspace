# @spidey3's QMK Community Modules

These rely on QMK Firmware 0.28.0 or later, merged in 2025q1.

Each child directory is a separate module, and has instructions on how to add it to your build.

| Module | Description |
| ------ | ----------- |
| [Better Debug](./better_deburg/) | More debugging modes, logs kb version, makes debug mode persistent |
| [Better RGB Keys](./better_rgb_keys/) | Adds autorepeat to `UG_*` HSV adjustment keycodes |
| [ChromeOS Goodies](./chromeos/) | Adds Fkey lock, suspend key, and other ChromeOS-specific goodies |
| [Glyph Replacement](./glyph_replacement/) | Translates boring typing into 🅕🅐🅝🅒🅨 𝕃𝕖𝕥𝕥𝕖𝕣𝕚𝕟𝕘 🆄🆂🅸🅽🅶 🅃🄷🄴 𝕸𝖆𝖌𝖎𝖈 𝓸𝓯 Unicode |
| [Miscellaneous Keys](./misc_keys/) | Emoji, keycodes that should be standard (but aren't), and make PrtSc better |
| [Shift-Backspace-Delete](./shift_bs_delete/) | Make shift+backspace send delete |
| [Startup RGB Animation](./startup_rgb_animation) | Show a pretty animation on your underglow LEDS on startup |
